# Job Habitat (preview)

Try it: https://vadneyk.github.io/job-habitat-app/

A free tool for career exploration. It helps autistic and neurodivergent adults find jobs whose usual work environment
(noise, lighting, contact with people, conflict, schedule) fits them.

- **Preview only.** The job numbers are made-up placeholders, not real O*NET data. Do not use the results to make decisions.
- **Private.** Everything runs in your browser. Your answers are never sent anywhere or saved.
- **Not a test or a diagnosis.**

This repository holds only the built page. It is generated from the main project, which is not public yet.
